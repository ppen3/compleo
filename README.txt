compleo v4 - PWA版（GitHub Pages）

- 新規インストール時は問題ゼロ件から開始。アプリ内に事前登録の問題データはありません。
- データ画面からCSVを読み込むと、登録済みの問題が追加・更新されます。
- 「問題を削除」では試験を選び、問題ID・問題文・章・節で検索し、チェックを付けて削除できます。
- 「表示中を全選択」で検索結果をまとめて選択できます。
- 削除した問題に結び付く学習履歴も削除されます。確認メッセージが表示されます。
- 削除前に「バックアップ」でJSONを保存することをおすすめします。
- CSVに含まれない既存問題は削除されません。不要な問題は削除画面から操作してください。
- 問題IDは試験内で一意（試験名 + IDがキー）。同じ組合せの再登録は上書き、学習履歴は保持。

標準CSV列：
id,exam,chapter,section,question,option1,option2,option3,option4,option5,answer,explanation,source

選択肢は空欄可で、一問一答にも対応。option6以降も追加可能（最大30個）。
正解が選択肢番号なら該当選択肢とともに解答カードへ表示されます。

【公開手順】
ZIP内の index.html、icon192.png、icon512.png、compleo_logo.jpg、manifest.webmanifest、sw.js を
GitHub Pagesに配置してください。購入問題集のCSVや学習履歴ファイルは公開しないでください。
アプリから取り込んだCSVはブラウザの端末内保存領域に保存し、外部サーバーには送信しません。
（ブラウザの保存データを削除すると消える可能性があるため、定期的にバックアップしてください。）

v3と同じURLで更新してもブラウザ内の既存問題は維持されます。
以前に端末内に登録された問題は、新版に更新しただけでは自動削除されません。
削除したい場合は「データ → 問題を削除」を使ってください。

GitHub Pagesで更新した場合、公開URLを再読み込みして新しい画面に更新してください。
